# ممیزی سیستم LMS اسبیکو

نسخه: 0.1

وضعیت: Audit در حال انجام

پروژه: Esbiko Science Web Lab

هدف:

این سند وضعیت فعلی سیستم مدیریت یادگیری (LMS) و معماری Classroom در اسبیکو را ثبت می‌کند.

* بررسی مالکیت (Ownership)
* بررسی دسترسی‌ها (Permissions)
* بررسی کنترل دسترسی (Access Control)
* بررسی امنیت Classroomها
* بررسی امنیت Assignmentها
* بررسی امنیت Submissionها

و دسته‌بندی آن‌ها در یکی از وضعیت‌های زیر:

* HARD ENFORCED

وضعیت:

SOFT ENFORCED

یافته‌های فعلی:

* TeacherClassDetail مالکیت کلاس را با teacherId بررسی می‌کند.

وضعیت:

یافته‌های فعلی:
